최종 업데이트: 2026년 10월 8일

한국어 English

요약

StickyPresenter에는 계정, 광고, 분석 도구, 추적이 없습니다. 사용자가 만든 노트·타이머·텔레프롬프터 대본은 Mac 안에만 머뭅니다. 정보가 Mac 밖으로 나가는 경우는 두 가지뿐이고, 둘 다 사용자가 직접 시작합니다. 피드백을 보낼 때, 그리고 iPhone의 Remote Controller 앱이 로컬 네트워크로 연결될 때입니다.

수집하는 정보

사용 통계, 광고 식별자, 위치 등 어떤 정보도 몰래 모으지 않습니다. 저희가 받는 정보는 사용자가 직접 보내는 피드백뿐입니다(아래 "피드백" 참고).

사용자 콘텐츠

노트·타이머·텔레프롬프터 글은 사용자의 Mac에만 저장됩니다(노트는 ~/Library/Application Support/StickyPresenter, 설정은 앱 환경설정). 알림 센터 위젯은 같은 Mac 안의 공유 저장소에서 타이머 상태를 읽어 옵니다. 이 중 어떤 것도 저희나 제3자에게 올라가지 않습니다.

클립보드

"클립보드에서 만들기"를 쓰거나 텔레프롬프터에 붙여 넣을 때, 그 글을 기기 안의 노트나 대본에 넣기 위해서만 클립보드를 읽습니다. 클립보드 내용을 따로 저장하거나 기록하거나 전송하지 않습니다.

피드백 (선택)

앱 설정에서 피드백을 보내면 사용자가 쓴 내용(피드백 종류와 메시지), 직접 적은 경우에만 이름과 이메일 주소, 그리고 문제를 고치는 데 필요한 기본 정보(앱 버전과 빌드, Mac 모델 식별자, macOS 버전, 언어·지역 설정)를 받습니다. 이 정보는 Apple iCloud(CloudKit)에 있는 저희 데이터베이스에 저장되며, 피드백을 읽고 답하고 반영하는 데만 씁니다. 보내기 버튼을 누르기 전에는 아무것도 전송되지 않습니다. 보낸 피드백을 지우고 싶으면 아래 주소로 메일을 주세요.

평가 요청

앱을 마음에 들어 하는지 물어볼 때를 정하려고 Mac 안에서 실행 횟수를 셉니다. 만족하신다면 Apple의 기본 평가 창을, 아쉽다면 피드백 화면을 보여 드립니다. 이 횟수는 Mac 밖으로 나가지 않습니다.

로컬 네트워크

Remote Controller iPhone 앱이 찾을 수 있도록, StickyPresenter는 Apple의 MultipeerConnectivity로 로컬 네트워크에 타이머 서비스(_sp-timer)를 알립니다. 이때 macOS가 로컬 네트워크 접근을 허용할지 물을 수 있습니다. 연결된 iPhone과는 타이머 정보(이름, 남은 시간, 상태, 위젯 크기, 테마, 화면 위 위젯 위치)와 사용자가 누른 명령만 주고받으며, 두 기기 사이에 직접 암호화된 연결로 오갑니다. 노트와 텔레프롬프터 대본은 전송되지 않습니다. 연결은 네 자리 페어링 코드로 보호됩니다. Mac 메뉴 막대 → Remote에 떠 있는 코드를 맞춘 iPhone과, 전에 그 코드를 통과해 Mac이 기억해 둔 iPhone만 연결할 수 있습니다. 코드와 기억해 둔 iPhone 목록은 Mac에만 저장됩니다. 기억해 둔 기기는 Forget Paired Remotes로 언제든 지울 수 있고, New Pairing Code로 코드를 새로 뽑을 수 있습니다. StickyPresenter를 종료하면 서비스 알림도 멈춥니다. 자세한 내용은 Remote Controller 개인정보처리방침을 참고하세요.

인터넷과 제3자

Apple iCloud로 피드백을 보내는 것 말고는 인터넷 요청을 하지 않습니다. 광고, 제3자 분석 도구, 추적이 없으며, 사용자 정보를 팔거나 다른 곳에 넘기지 않습니다.
