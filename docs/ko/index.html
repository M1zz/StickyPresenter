대본과 남은 시간을 늘 눈앞에

StickyPresenter는 Keynote 전체 화면을 포함한 발표 화면 위에 스티키 노트, 카운트다운 타이머, 텔레프롬프터를 띄워 두는 가벼운 macOS 메뉴 막대 앱입니다. 발표하는 동안에도 메모와 시간이 늘 보입니다.

  • 화면 위에 떠 있는 스티키 노트 — 전체 화면 슬라이드 위에도 그대로 보입니다. 여섯 가지 색, 투명도와 글자 크기 조절, 실수로 글이 바뀌지 않게 막는 잠금까지.
  • 타이머 — 크기를 바꿀 수 있는 카운트다운 위젯. 시간이 다 되면 차임과 깜박이는 테두리로 알려 줍니다. 별도 창으로 열면 화면 공유나 AirPlay에도 띄울 수 있습니다.
  • 텔레프롬프터 — 저절로 올라가는 대본. 속도와 글자 크기를 조절하고 좌우 반전 모드도 씁니다.
  • 메뉴 막대에서 조용히 — Dock 아이콘도, 따로 챙겨야 할 창도 없습니다.

함께 쓰는 앱

iPhone 리모컨, Remote Controller

발표 중에는 Mac이 손에 닿지 않습니다. Remote Controller는 타이머를 손안으로 가져옵니다. 시작과 일시정지, 30초 더하기, 위젯 크기 조절, 슬라이드를 가릴 때 Mac 화면 위에서 위치 옮기기까지 할 수 있습니다. 같은 네트워크에서 계정 없이 바로 연결됩니다.
