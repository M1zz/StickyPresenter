어떤 앱인가요

Remote Controller는 macOS용 StickyPresenter의 iPhone 리모컨입니다. 발표 중에는 Mac이 손에 닿지 않는 곳에 있기 마련인데, 이 앱이 타이머 조작을 손안으로 가져옵니다. 단독으로 쓰는 앱이 아니라, 같은 Wi-Fi에 있는 Mac에서 StickyPresenter가 실행 중이어야 합니다.

할 수 있는 것

  • 남은 시간 보기 — 남은 시간·진행률과 뽀모도로 구간(집중/휴식), 몇 번째 사이클인지를 1초마다 갱신해 보여줍니다.
  • 시작·일시정지·초기화 — 이야기가 길어질 때 30초 더하기/빼기도 그 자리에서.
  • 새 타이머 시작 — 3분 / 5분 / 10분 / 15분 프리셋.
  • 위젯 크기 조절 — S / M / L. 뒷자리에서도 읽히게.
  • 위젯 위치 옮기기 — Mac의 화면 배치를 축소해 그린 판에서 끌면 됩니다. 슬라이드를 가리면 Mac에 손대지 않고 타이머를 비켜 놓을 수 있고, 확장 디스플레이라면 옆 화면으로 넘길 수도 있습니다.
  • 감추기·정렬·삭제 — 청중에게서 위젯을 감추거나, 놓친 위젯을 패널 옆으로 다시 불러오거나, 타이머를 지웁니다.

준비물

  • iOS 17 이상의 iPhone
  • 같은 Wi-Fi에 있고 StickyPresenter가 실행 중인 Mac
  • 양쪽 기기에서 로컬 네트워크 접근 허용

연결 방식

두 앱은 로컬 네트워크에서 서로를 찾아(Bonjour / Apple MultipeerConnectivity) 직접 주고받습니다. 만들 계정도, 중간에 거치는 서버도 없습니다. 타이머와 명령은 로컬 네트워크 밖으로 나가지 않습니다. 인터넷으로 나가는 것은 익명 사용 통계· 크래시 보고·직접 보내신 의견뿐입니다 — 개인정보처리방침을 참고하세요.

처음 한 번만 연결 코드를 넣습니다. 앱을 열면 주변에서 찾은 Mac이 목록에 뜹니다. 내 Mac을 고르고, Mac 메뉴 막대의 타이머 아이콘 → Remote에 떠 있는 네 자리 코드를 입력하면 짝이 맺어집니다. 그다음부터는 앱만 열면 그 Mac에 저절로 붙습니다.

회의실처럼 같은 Wi-Fi에 Mac이 여러 대 있어도 안심하세요 — 리모컨은 짝을 맺은 Mac 한 대에만 붙고, 코드를 모르는 리모컨은 내 Mac에 붙지 못합니다.

연결이 안 될 때

연결에 실패하면 앱이 이유와 할 일을 알려 줍니다.

  • 연결 코드가 다릅니다 — Mac 메뉴 막대의 타이머 아이콘 → Remote에 지금 떠 있는 네 자리를 넣으세요. New Pairing Code를 눌렀다면 새 코드만 맞습니다.
  • Mac이 이 iPhone을 기억하지 못합니다 — Mac에서 Forget Paired Remotes를 눌렀거나 StickyPresenter를 다시 설치한 경우입니다. 목록에서 Mac을 눌러 코드를 다시 넣으세요.
  • Mac에서 응답이 없습니다 — Mac이 잠자기 상태가 아닌지, 두 기기가 같은 Wi-Fi인지, VPN이 꺼져 있는지 확인하세요.
  • 10초 넘게 Mac이 보이지 않습니다 — 점검표가 나타납니다. Mac에서 StickyPresenter 실행, 같은 Wi-Fi(게스트 네트워크 아님), iPhone과 Mac의 로컬 네트워크 허용, VPN 끄기를 위에서부터 하나씩 확인하세요.
  • Mac 앱 업데이트가 필요합니다 — Mac의 StickyPresenter를 업데이트한 다음 다시 고르세요.

더 자세한 내용은 지원 페이지를 참고하세요.
