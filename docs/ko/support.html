시작하기

StickyPresenter는 메뉴바(📝 아이콘)에서 동작합니다. 아이콘을 눌러 스티키 노트를 만들거나 타이머·텔레프롬프터를 열 수 있습니다. Dock 아이콘 없이 백그라운드에서 조용히 실행됩니다.

주요 기능

  • 플로팅 스티키 노트 — Keynote 전체 화면 위에도 표시, 6가지 색상, 투명도·폰트 크기·잠금 지원.
  • 타이머 — 크기 조절 가능한 정사각형 카운트다운 위젯. 테마(라이트/다크), 표시/감추기, 패널 옆 정렬, 화면 공유·AirPlay용 별도 윈도우로 열기. 종료 시 차임과 테두리 펄스로 알림.
  • 텔레프롬프터 — 자동 스크롤 대본, 속도·폰트 크기 조절, 좌우 반전(미러) 모드.

자주 묻는 질문

화면 미러링에서 타이머를 윈도우로 추가할 수 있나요?
네. 타이머 행의 Window 버튼으로 실제 윈도우로 열면 미러링/화면 공유의 "윈도우 추가" 목록에 표시됩니다.

타이머 위젯을 감췄는데 어디 있는지 모르겠어요.
패널에서 해당 타이머 행에 마우스를 올리면 점선으로 위치를 보여줍니다. 불러오기(Align)를 누르면 패널 옆으로 다시 가져옵니다.

리모컨 앱 (iPhone)

Remote Controller 앱으로 iPhone에서 타이머를 조작합니다 — 시작·일시정지, 30초 더하기/빼기, 위젯 크기 조절, Mac 화면 위에서 위치 옮기기, 감추기, 프리셋 타이머 시작. 같은 Wi-Fi의 Mac에서 StickyPresenter가 실행 중이어야 합니다.

처음 연결하기. 앱을 열면 주변에서 찾은 Mac 목록이 나옵니다. 내 Mac을 고른 다음, Mac 메뉴 막대의 타이머 아이콘을 눌러 Remote 안에 떠 있는 네 자리 Pairing Code를 입력하세요. 한 번 맞추면 Mac이 그 iPhone을 기억하므로 다음부터는 앱만 열면 저절로 붙습니다. 다른 Mac으로 옮기려면 리모컨 오른쪽 위의 연결 표시를 눌러 연결 해제하고 다시 고르기를 선택하세요.

Mac을 찾지 못할 때 순서대로 확인하세요.

  • Mac에서 StickyPresenter가 실행 중인지 — 메뉴 막대의 아이콘으로 확인합니다. 창을 모두 닫아도 앱은 남아 있지만, 종료하면 리모컨이 찾지 못합니다.
  • 두 기기가 같은 Wi-Fi인지. 게스트 네트워크이거나 한쪽이 셀룰러면 찾지 못합니다.
  • iPhone의 로컬 네트워크 허용 — 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → Remote Controller.
  • Mac의 로컬 네트워크 허용 — 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → StickyPresenter.
  • VPN을 끄세요. 같은 네트워크의 기기를 못 찾게 하는 흔한 원인입니다.

연결 코드가 맞지 않는다고 나옵니다. Mac 메뉴 막대 → Remote에 지금 떠 있는 코드를 그대로 넣었는지 확인하세요. New Pairing Code를 누른 적이 있으면 코드가 바뀌어 있습니다.

연결에 실패하면 이제 앱이 이유와 할 일을 따로 알려 줍니다 — 연결이 안 될 때를 참고하세요.

다른 사람이 제 타이머를 조작할 수도 있나요? 코드를 알려주지 않는 한 조작할 수 없습니다. Mac은 코드가 맞는 리모컨과 전에 코드를 통과한 리모컨의 연결만 받아들입니다. 코드를 보여준 적이 있어 되돌리고 싶다면 Mac 메뉴 막대 → Remote에서 New Pairing Code로 코드를 새로 뽑거나, Forget Paired Remotes로 기억해 둔 리모컨을 모두 지우세요. 자세한 내용은 Remote Controller 개인정보처리방침을 참고하세요.
