概要

StickyPresenter には、アカウントも広告もトラッキングもありません。 付箋、タイマー、プロンプターの原稿はお使いの Mac の中だけに保存されます。匿名の利用統計 （後述）を除き、情報が Mac の外に出るのは次の 2 つの場合だけで、どちらもお客様ご自身の 操作がきっかけです。ひとつはフィードバックを送信したとき、もうひとつは iPhone の Remote Controller アプリがローカルネットワーク経由で接続したときです。

収集するデータ

広告識別子、位置情報、その他の個人情報は一切収集しません。当方が受け取るのは、下記の 匿名統計と、お客様が送信を選んだフィードバック（後述の「フィードバック」を参照）のみです。

匿名の利用統計

アプリの利用者数や、まだ使われているバージョンを把握するため、StickyPresenter は Apple の iCloud（CloudKit）に匿名の統計を送信します。この統計を閲覧できるのは開発者のみです。

  • アプリのインストール時に生成されるランダムな ID（お客様本人、Apple ID、Mac、 他のアプリとは結び付かず、再インストールすると変わります）
  • アプリのバージョン、macOS のバージョン、地域と言語の設定
  • アプリを開いた回数、開いた日、インストール日、およびインストールからの経過日数

氏名、連絡先、位置情報、付箋の内容などは一切含まれません。統計は iCloud に サインインしている場合にのみ送信されます。

お客様のコンテンツ

作成した付箋、タイマー、プロンプターのテキストは、お使いの Mac にのみ保存されます （付箋は ~/Library/Application Support/StickyPresenter、設定はアプリの環境設定）。 通知センターのウィジェットは、同じ Mac 上の共有コンテナからタイマーの状態を読み取ります。 これらが当方や第三者にアップロードされることはありません。

クリップボード

「クリップボードから作成」を選んだときや、プロンプターに貼り付けたときに限り、 そのテキストをデバイス上の付箋や原稿に入れる目的でクリップボードを読み取ります。 クリップボードの内容を別途保存・記録・送信することはありません。

フィードバック（任意）

アプリの設定からフィードバックを送信した場合、当方が受け取るのは、ご記入いただいた内容 （フィードバックの種類とメッセージ）、ご入力いただいた場合に限り氏名とメールアドレス、 そして不具合の解決に役立つ基本的な技術情報（アプリのバージョンとビルド、Mac の機種 ID、 macOS のバージョン、言語と地域の設定）です。これらは Apple の iCloud（CloudKit）上の 当方のデータベースに保存され、フィードバックを読み、返信し、対応するためにのみ使用されます。 「送信」を押すまでは何も送られません。フィードバックの削除をご希望の場合は、下記の メールアドレスまでご連絡ください。

評価のお願い

アプリは、満足度をおうかがいするタイミングを決めるため、Mac 上で起動回数を数えています。 満足しているとお答えいただいた場合は Apple 標準の評価画面を、そうでない場合は フィードバックフォームを表示します。この回数が Mac の外に送られることはありません。

ローカルネットワーク

iPhone の Remote Controller アプリから見つけられるよう、 StickyPresenter は Apple の MultipeerConnectivity を使ってローカルネットワーク上に タイマーサービス（_sp-timer）を公開します。その際、macOS からローカル ネットワークへのアクセス許可を求められることがあります。接続した iPhone とやり取りするのは、 タイマーの情報（名前、残り時間、状態、ウィジェットのサイズ、テーマ、画面上でのウィジェットの 位置）とお客様がタップした操作だけで、通信は暗号化され、2 台の間で直接行われます。付箋や プロンプターの原稿が送られることはありません。接続には4 桁のペアリングコードが 必要です。接続できるのは、メニューバー →「リモコン」に表示されるコードと一致した iPhone か、 以前にそのコードで認証して Mac に記憶されている iPhone だけです。コードと記憶済み iPhone の 一覧は Mac に保存されます。「ペアリング済みのリモコンを解除」でいつでも記憶済みのデバイスを すべて消去でき、「新しいペアリングコード」で新しいコードを発行することもできます。 StickyPresenter を終了すると、サービスの公開も停止します。詳しくは Remote Controller のプライバシーポリシーをご覧ください。

インターネットと第三者

フィードバックの送信と、上記の匿名統計を Apple の iCloud 経由で送る場合を除き、 アプリがインターネットに接続することはありません。広告、第三者の分析 SDK、トラッキングは 一切含まれておらず、お客様の情報を誰かに販売・共有することもありません。

お子様について

本アプリが、お子様から意図的に情報を収集することはありません。

変更について

本ポリシーを変更した場合は、新しい「最終更新日」を付けてこのページに掲載します。
