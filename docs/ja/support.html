はじめに

StickyPresenter はメニューバーに常駐しています（📝 アイコン）。アイコンをクリックすると、 付箋の作成、タイマーの表示、プロンプターの開始ができます。Dock にアイコンは表示されず、 バックグラウンドで静かに動作します。

機能

  • 前面に浮かぶ付箋 — フルスクリーンの Keynote の上にも表示。6 色、不透明度と文字サイズの調整、ロックに対応しています。
  • タイマー — 正方形のカウントダウンウィジェット。サイズ変更、テーマ（ライト／ダーク）の切り替え、表示／非表示、パネル横への整列ができ、別ウインドウで開けば画面共有や AirPlay にも使えます。時間になるとチャイムが鳴り、枠が点滅してお知らせします。
  • プロンプター — 原稿を自動スクロール。速度と文字サイズの調整、ミラーモードに対応しています。

よくある質問

画面ミラーリングのとき、タイマーウインドウをソースとして追加できますか？
はい。タイマーの行にある「ウインドウ」ボタンを押すと、通常のウインドウとして開きます。 このウインドウは、ミラーリングや画面共有の「ウインドウを追加」の一覧に表示されます。

タイマーのウィジェットを非表示にしたら、どこにあるかわからなくなりました。
パネルでそのタイマーの行にポインタを重ねると、位置が点線の枠で表示されます。 または「整列」を押すと、パネルの横に戻ってきます。

Remote Controller（iPhone）

Remote Controller アプリを使うと、iPhone からタイマーを 操作できます。スタートと一時停止、30 秒の追加・短縮、ウィジェットのサイズ変更、Mac の画面上の 別の場所へのドラッグ移動、非表示、プリセットタイマーの開始が可能です。同じ Wi-Fi に つながった Mac で StickyPresenter が起動している必要があります。

初めて接続するとき アプリを開くと、近くにある Mac が一覧表示されます。 お使いの Mac を選んだら、Mac のメニューバーにあるタイマーアイコンをクリックし、「リモコン」の 下に表示される 4 桁の「ペアリングコード」を入力してください。コードが一致すると Mac がその iPhone を記憶し、次回からはアプリを開くだけで自動的に接続されます。別の Mac に切り替えるには、 リモコン画面右上の接続表示をタップし、「接続を解除して選び直す」を選んでください。

Mac が見つかりません。 次の順に確認してください。

  • Mac で StickyPresenter が起動しているか — メニューバーにアイコンがあるか確認します。 ウインドウをすべて閉じても終了はしませんが、アプリを終了するとリモコンから見つけられなくなります。
  • 両方のデバイスが同じ Wi-Fi につながっているか。ゲスト用ネットワークや、 片方がモバイル通信の場合は接続できません。
  • iPhone でローカルネットワークが許可されているか — 設定 → プライバシーとセキュリティ → ローカルネットワーク → Remote Controller。
  • Mac でローカルネットワークが許可されているか — システム設定 → プライバシーとセキュリティ → ローカルネットワーク → StickyPresenter。
  • VPN をオフにする。VPN を使っていると、同じネットワーク上の他のデバイスが見えなくなることがよくあります。

ペアリングコードが一致しないと表示されます。 Mac のメニューバー →「リモコン」に 現在表示されているコードを入力しているか確認してください。「新しいペアリングコード」を押した場合は、 コードが変わっています。

接続に失敗したときは、アプリがその理由と対処方法を個別に表示するようになりました。詳しくは接続できないときをご覧ください。

他の人に自分のタイマーを操作されることはありませんか？ コードを教えない限り ありません。Mac が受け付けるのは、正しいコードを入力したリモコンと、以前にコードで認証済みの リモコンだけです。誰かにコードを見せてしまい、それを取り消したい場合は、メニューバー →「リモコン」→ 「新しいペアリングコード」で新しいコードを発行するか、「ペアリング済みのリモコンを解除」で 記憶済みのリモコンをすべて消去してください。詳しくは Remote Controller のプライバシーポリシーをご覧ください。
