原稿も残り時間も、いつも目の前に

StickyPresenter は、メニューバーに常駐する軽量な macOS アプリです。フルスクリーンの Keynote をはじめ、どんなプレゼンの上にも付箋・カウントダウンタイマー・プロンプターを 表示できるので、発表中もメモと時間を見失いません。

  • 前面に浮かぶ付箋 — フルスクリーンのスライドの上にも表示されます。6 色から選べ、不透明度や文字サイズも調整可能。うっかり書き換えないようロックもできます。
  • タイマー — サイズを自由に変えられるカウントダウンウィジェット。時間になるとチャイムが鳴り、枠が点滅してお知らせします。別ウインドウで開けば、画面共有や AirPlay でそのまま映せます。
  • プロンプター — 原稿が自動でスクロールし、速度と文字サイズを調整できます。ミラーモードにも対応。
  • メニューバーに常駐 — Dock にアイコンは出ず、管理すべきウインドウも増えません。

関連アプリ

iPhone 用 Remote Controller

発表中は Mac に手が届きません。Remote Controller があれば、タイマーを 手元で操作できます。スタートと一時停止、30 秒の追加、ウィジェットのサイズ変更、さらに スライドに重なってしまったときは Mac の画面上の別の場所へドラッグで移動することも。 ローカルネットワーク経由でつながるので、アカウントも面倒な設定も不要です。
