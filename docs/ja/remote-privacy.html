概要

Remote Controller にはアカウントも広告もトラッキングもなく、個人情報を収集する こともありません。タイマーと操作の内容は、お客様のローカルネットワーク内で、iPhone と StickyPresenter が起動している Mac の間だけでやり取りされます。それ以外にアプリが送信するのは、 匿名の利用統計、クラッシュレポート、お客様が送信したフィードバックだけです。これらはすべて Apple の iCloud（CloudKit）を通じて送られ、開発者だけが閲覧します。

収集するデータ

お名前、連絡先、位置情報、広告識別子、タイマーの内容は収集しません。受け取るのは、以下の 匿名の統計とクラッシュレポート、そしてお客様ご自身が送信したフィードバックだけです。

匿名の利用統計

アプリの利用者数や、どのバージョンがまだ使われているかを把握するため、アプリは次の情報を送信します。

  • アプリのインストール時に作られるランダムな ID（お客様、Apple アカウント、iPhone、他のアプリの いずれとも結び付かず、再インストールすると変わります）
  • アプリのバージョン、iOS のバージョン、デバイスの種類、地域と言語の設定
  • アプリを開いた回数と日、インストール日、インストールからの経過日数

統計は iCloud にサインインしている場合にのみ送信されます。

クラッシュレポート

アプリがクラッシュしたりフリーズしたりすると、iOS が診断レポート（Apple の MetricKit）を アプリに渡します。通常は 1 日に 1 回程度です。アプリはそのうちのコールスタック、アプリのバージョン、 iOS のバージョン、デバイスの種類を転送します。上記のランダムな ID を含め、識別子は一切付きません。

フィードバック

設定 → ご意見を送る からフィードバックを送信すると、お書きになった内容、任意で添えた連絡先、 そして問題を再現するためのアプリのバージョン、iOS のバージョン、デバイスのモデルを受け取ります。 iCloud が使えない場合は、代わりにメールで送る方法をご案内します。

iPhone に保存されるもの

コードを再入力せずに再接続できるよう、アプリは iPhone に 2 つの値を保存します。この インストール用に作られたランダムな識別子と、ペアリングした Mac の識別子です。どちらもお客様や Apple アカウントとは結び付かず、ペアリングした Mac とだけ共有され、ペアリングを解除するか アプリを削除すると消去されます。

ローカルネットワーク

このアプリの目的は Mac のタイマーを操作することだけなので、ローカルネットワークへの アクセス許可が必要です。Apple の MultipeerConnectivity フレームワークを使い、同じネットワーク上で StickyPresenter のタイマーサービス（_sp-timer）を公開している Mac を見つけて接続します。 通信は iPhone と Mac の間で直接行われ、暗号化されています。許可しない場合、アプリは Mac を 見つけられず、ほかの機能も使えません。

やり取りする情報

リモコン画面の表示と、タップした操作の実行に必要なものだけです。

  • タイマーの情報 — 名前、残り時間と目標時間、実行中／終了／非表示の状態、ポモドーロの フェーズとサイクル、ウィジェットのサイズ、テーマ、Mac の画面配置の中でのウィジェットの位置。
  • お客様の操作 — スタート、一時停止、リセット、30 秒の追加・短縮、サイズ変更、移動、非表示、 整列、削除、プリセットタイマーの作成。
  • デバイス名 — 検出の過程で、iPhone のデバイス名が Mac に、Mac のコンピュータ名がアプリに 表示されます。これは Apple の MultipeerConnectivity が相手を識別するしくみで、同じネットワーク上で このサービスを探しているデバイスからも見えます。

付箋やプロンプターの原稿が iPhone に送られることはありません。

接続できる人

接続には4 桁のペアリングコードが必要です。コードは Mac のメニューバーの タイマーアイコン → リモコンに表示され、初めて接続するときにこのアプリで 1 回だけ 入力します。コードが一致すると Mac がその iPhone を記憶し、次回からはコードなしで接続できます。

コードを知らないデバイスは、同じローカルネットワーク上にあっても接続できません。このアプリは 近くで見つかった Mac を一覧にするだけで、データをやり取りするのはペアリングした 1 台の Mac だけです。 Mac では 新しいペアリングコードでコードを作り直したり、 ペアリング済みのリモコンを解除で記憶済みのデバイスをすべて消去したりできます。 このアプリでは、接続表示をタップしてペアリングを解除できます。やり取りするのは上記のタイマー情報だけで、 操作できるのもタイマーだけです。Mac の StickyPresenter を終了すると、検出されなくなります。

インターネット・広告・トラッキング

上記の統計、クラッシュレポート、フィードバックと、アプリをアップデートしなくても不具合のある機能を 止められるようにするための小さなオン／オフ設定の読み込みを除き、アプリがインターネットに接続する ことはありません。広告、トラッキング、第三者の SDK は一切含まれず、追跡するものがないため App Tracking Transparency フレームワークも使用していません。お客様の情報を誰かに販売・共有する こともありません。

お子様について

このアプリは、お子様を含むどなたからも、個人情報を意図的に収集することはありません。
