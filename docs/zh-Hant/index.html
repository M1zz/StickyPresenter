講稿和時間，隨時一目了然

StickyPresenter 是一款輕巧的 macOS 選單列 App，能讓便利貼、倒數計時器和提詞機 浮動顯示在全螢幕的 Keynote 或任何簡報上方。上台時，筆記與時間始終都在眼前。

  • 浮動便利貼：始終顯示在全螢幕投影片上方，提供六種顏色，可調整透明度與字體大小，還能鎖定以免不小心改動。
  • 計時器：可自由調整大小的倒數小工具，時間到時會發出提示音並讓邊框閃動。也能在獨立視窗中開啟，透過螢幕分享或 AirPlay 與觀眾共享。
  • 提詞機：講稿自動捲動，可調整速度與字體大小，並支援鏡像模式。
  • 常駐選單列：不佔用 Dock，也不會多出一堆需要管理的視窗。

搭配 App

iPhone 版 Remote Controller

演講時，Mac 往往不在手邊。Remote Controller 讓你把計時器握在手中： 開始與暫停、增加 30 秒、調整小工具大小，擋到投影片時還能把它拖到 Mac 螢幕上的其他位置。 透過區域網路連線，不需要帳號，也不必另外設定。
