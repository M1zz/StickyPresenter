開始使用

StickyPresenter 常駐在選單列（📝 圖示）。點一下這個圖示，就能建立便利貼、開啟計時器或啟動提詞機。 這款 App 不會出現在 Dock 中，會在背景安靜執行。

功能

  • 浮動便利貼：始終顯示在全螢幕 Keynote 上方，提供 6 種顏色，可調整透明度與字體大小，並可鎖定。
  • 計時器：方形倒數小工具，可調整大小、切換主題（淺色／深色）、顯示／隱藏、對齊到面板旁，或在獨立視窗中開啟，方便透過螢幕分享和 AirPlay 共享。時間到時會發出提示音並讓邊框閃動。
  • 提詞機：講稿自動捲動，可調整速度與字體大小，並支援鏡像模式。

常見問題

計時器視窗可以在螢幕鏡像時加入為來源嗎？
可以。按下計時器那一列的視窗按鈕，就會以真正的視窗開啟， 並出現在鏡像／螢幕分享的「加入視窗」清單中。

我把計時器小工具隱藏起來後找不到了。
將游標移到面板中該計時器的那一列，就能看到它的位置（以虛線外框標示）；或按下 對齊，讓它回到面板旁邊。

Remote Controller（iPhone）

Remote Controller App 讓你用 iPhone 操作計時器： 開始與暫停、增減 30 秒、調整小工具大小、把它拖到 Mac 螢幕上的其他位置、將它隱藏，或啟動預設計時器。 使用前，同一個 Wi-Fi 網路上的 Mac 必須正在執行 StickyPresenter。

第一次連線。打開 App 後，它會列出附近找到的 Mac。選擇你的 Mac， 接著點一下 Mac 選單列中的計時器圖示，輸入 遙控 下方顯示的四位數配對碼。 配對成功後，Mac 就會記住這支 iPhone，之後只要打開 App 就會自動連線。若要改連其他 Mac， 請點一下遙控器右上角的連線狀態指示，然後選擇中斷連線並重新選擇。

找不到我的 Mac。請依序檢查：

  • Mac 上的 StickyPresenter 是否正在執行，請確認選單列中有沒有它的圖示。關閉所有視窗並不會結束 App，但結束 App 之後，遙控器就找不到它了。
  • 兩台裝置是否連上同一個 Wi-Fi。訪客網路，或其中一台使用行動網路時，都無法連線。
  • iPhone 是否已允許區域網路存取：設定 → 隱私權與安全性 → 區域網路 → Remote Controller。
  • Mac 是否已允許區域網路存取：系統設定 → 隱私權與安全性 → 區域網路 → StickyPresenter。
  • 關閉所有 VPN。VPN 常會讓同一網路中的其他裝置無法被看見。

顯示配對碼不符。請確認你輸入的是 Mac 上選單列 → 遙控 目前顯示的配對碼。 如果你按過產生新的配對碼，配對碼就已經變更。另外，當 Mac 處於睡眠狀態或未連上 Wi-Fi 而完全沒有回應時， 也會出現相同的訊息。

別人能操控我的計時器嗎？除非你把配對碼告訴對方，否則不行。 Mac 只接受輸入正確配對碼的遙控器，以及先前已通過配對碼驗證的遙控器。若你曾把配對碼給別人看過、想要撤銷， 請使用選單列 → 遙控 → 產生新的配對碼重新產生一組配對碼，或使用 清除已配對的遙控器移除所有已記住的遙控器。詳情請參閱 Remote Controller 隱私權政策。
