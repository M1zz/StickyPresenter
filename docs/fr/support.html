Premiers pas

StickyPresenter se trouve dans votre barre des menus (l’icône 📝). Cliquez dessus pour créer des notes, ouvrir des minuteurs ou lancer le prompteur. L’app n’a pas d’icône dans le Dock et fonctionne discrètement en arrière-plan.

Fonctionnalités

  • Notes flottantes : elles restent au premier plan, même sur Keynote en plein écran. 6 couleurs, opacité et taille de police réglables, et verrouillage.
  • Minuteurs : des widgets carrés de compte à rebours que vous pouvez redimensionner, passer en thème clair ou sombre, afficher ou masquer, aligner à côté du panneau, ou ouvrir dans leur propre fenêtre pour le partage d’écran et AirPlay. Un carillon et un contour qui clignote signalent la fin du temps.
  • Prompteur : un texte qui défile tout seul, avec vitesse et taille de police réglables, et un mode miroir.

Questions fréquentes

Puis-je ajouter la fenêtre du minuteur comme source lors de la recopie de l’écran ?
Oui. Utilisez le bouton Fenêtre sur la ligne d’un minuteur pour l’ouvrir dans une vraie fenêtre, qui apparaît alors dans la liste « ajouter une fenêtre » de votre outil de recopie ou de partage d’écran.

J’ai masqué un widget de minuteur et je ne le retrouve plus.
Survolez la ligne du minuteur dans le panneau pour voir son emplacement (un contour en pointillés), ou appuyez sur Aligner pour le replacer à côté du panneau.

Remote Controller (iPhone)

L’app Remote Controller pilote vos minuteurs depuis votre iPhone : lancement et pause, ajout ou retrait de 30 secondes, redimensionnement du widget, déplacement ailleurs sur l’écran du Mac, masquage, ou démarrage d’un minuteur prédéfini. StickyPresenter doit être ouvert sur un Mac connecté au même réseau Wi-Fi.

Première connexion. Ouvrez l’app : elle affiche les Mac qu’elle trouve à proximité. Choisissez le vôtre, puis cliquez sur l’icône de minuteur dans la barre des menus du Mac et saisissez le Code d’appairage à quatre chiffres affiché sous Télécommande. Une fois le code validé, le Mac se souvient de cet iPhone : par la suite, l’app se connecte toute seule dès que vous l’ouvrez. Pour passer à un autre Mac, touchez l’indicateur de connexion en haut à droite de la télécommande et choisissez Se déconnecter et choisir à nouveau.

L’app ne trouve pas mon Mac. Vérifiez dans l’ordre :

  • StickyPresenter est bien ouvert sur le Mac : son icône doit apparaître dans la barre des menus. Fermer toutes les fenêtres ne quitte pas l’app, mais si vous la quittez, la télécommande ne peut plus la trouver.
  • Les deux appareils sont sur le même réseau Wi-Fi. Un réseau invité, ou un appareil en données cellulaires, ne fonctionnera pas.
  • L’accès au réseau local est autorisé sur l’iPhone : Réglages → Confidentialité et sécurité → Réseau local → Remote Controller.
  • L’accès au réseau local est autorisé sur le Mac : Réglages Système → Confidentialité et sécurité → Réseau local → StickyPresenter.
  • Désactivez tout VPN : il masque souvent les autres appareils du même réseau.

Le message indique que le code d’appairage ne correspond pas. Vérifiez que vous avez saisi le code actuellement affiché dans la barre des menus du Mac → Télécommande. Si vous avez appuyé sur Nouveau code d’appairage, le code a changé. Le même message s’affiche aussi lorsque le Mac est en veille ou n’est plus connecté au Wi-Fi, et ne répond donc pas.

Quelqu’un d’autre peut-il contrôler mes minuteurs ? Pas si vous ne lui donnez pas le code. Le Mac n’accepte que les télécommandes qui saisissent le bon code, ainsi que celles qui l’ont déjà saisi par le passé. Si vous avez montré le code à quelqu’un et souhaitez revenir en arrière, utilisez la barre des menus → Télécommande → Nouveau code d’appairage pour générer un nouveau code, ou Oublier les télécommandes appairées pour effacer toutes les télécommandes mémorisées. Pour en savoir plus, consultez la politique de confidentialité de Remote Controller.
