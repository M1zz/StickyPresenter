De quoi s’agit-il ?

Remote Controller est la télécommande iPhone de StickyPresenter pour Mac. Pendant votre présentation, votre Mac est souvent hors de portée : cette app vous met les commandes du minuteur dans la main. Elle ne fonctionne pas seule : StickyPresenter doit être ouvert sur un Mac connecté au même réseau Wi-Fi.

Ce que vous pouvez faire

  • Suivre le décompte — temps restant, progression et phase Pomodoro (Concentration / Pause) avec le numéro du cycle, mis à jour chaque seconde.
  • Lancer, mettre en pause, réinitialiser — et ajouter ou retirer 30 secondes en pleine intervention quand une partie s’éternise.
  • Lancer un nouveau minuteur — préréglages de 3 / 5 / 10 / 15 minutes.
  • Redimensionner le widget — S / M / L, pour qu’on le lise jusqu’au fond de la salle.
  • Déplacer le widget — faites-le glisser sur une miniature de la disposition des écrans de votre Mac. S’il cache une diapositive, écartez le minuteur sans toucher au Mac. Avec un écran externe, faites-le passer sur l’autre écran.
  • Masquer, aligner, supprimer — cachez le widget au public, ramenez un widget égaré à côté du panneau ou supprimez le minuteur.

Configuration requise

  • Un iPhone sous iOS 17 ou version ultérieure
  • Un Mac sur lequel StickyPresenter est ouvert, sur le même réseau Wi-Fi
  • L’accès au réseau local autorisé sur les deux appareils

Comment se fait la connexion

Les deux apps se trouvent sur votre réseau local (Bonjour / MultipeerConnectivity d’Apple) et communiquent directement entre elles. Aucun compte à créer, aucun serveur intermédiaire. Vos minuteurs et vos commandes ne quittent jamais votre réseau local ; seuls des statistiques d’utilisation anonymes, des rapports de plantage et les commentaires que vous choisissez d’envoyer passent par Internet — voir la politique de confidentialité.

Le code ne se saisit qu’une fois. Ouvrez l’app : les Mac trouvés à proximité s’affichent dans une liste. Choisissez le vôtre et saisissez le code à quatre chiffres affiché sur le Mac sous l’icône du minuteur dans la barre des menus → Télécommande : les deux appareils sont appairés. Ensuite, l’app se connecte toute seule à ce Mac dès que vous l’ouvrez.

Plusieurs Mac sur le même Wi-Fi, dans une salle de réunion par exemple ? Aucun problème : la télécommande ne dialogue qu’avec le Mac auquel elle est appairée, et une télécommande qui ne connaît pas votre code ne peut pas atteindre votre Mac.

Si la connexion échoue

L’app vous indique pourquoi la connexion a échoué et quoi faire :

  • Code incorrect — saisissez les quatre chiffres affichés en ce moment sous l’icône du minuteur dans la barre des menus → Télécommande. Si vous avez cliqué sur Nouveau code d’appairage, seul le nouveau code fonctionne.
  • Le Mac ne reconnaît plus cet iPhone — cela arrive après Oublier les télécommandes appairées ou une réinstallation de StickyPresenter. Touchez le Mac dans la liste et saisissez à nouveau le code.
  • Le Mac ne répond pas — vérifiez que le Mac n’est pas en veille, que les deux appareils sont sur le même Wi-Fi et qu’aucun VPN n’est activé.
  • Aucun Mac trouvé depuis plus de 10 secondes — une liste de vérifications s’affiche : StickyPresenter ouvert sur le Mac, même Wi-Fi (pas un réseau invité), réseau local autorisé sur l’iPhone et sur le Mac, VPN désactivé. Parcourez-la dans l’ordre.
  • L’app Mac doit être mise à jour — mettez à jour StickyPresenter sur le Mac, puis choisissez-le à nouveau.
