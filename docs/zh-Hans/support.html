快速上手

StickyPresenter 常驻在菜单栏中（📝 图标）。点按它即可新建便签、打开计时器或启动提词器。 本应用没有程序坞图标，会在后台安静运行。

功能

  • 悬浮便签：始终显示在全屏 Keynote 上方，提供 6 种颜色，可调整透明度和字号，并可锁定。
  • 计时器：方形倒计时小组件，可调整大小、切换主题（浅色/深色）、显示或隐藏、对齐到面板旁边，也可以在单独的窗口中打开，用于屏幕共享和 AirPlay。时间到时会响起提示音，边框也会闪动提醒。
  • 提词器：讲稿自动滚动，可调节速度和字号，并支持镜像模式。

菜单栏操作

操作位置
新建便签菜单栏 → 新建便签
从剪贴板新建菜单栏 → 从剪贴板新建
打开计时器菜单栏 → 计时器
提词器菜单栏 → 提词器模式
显示/隐藏所有便签菜单栏 → 显示所有便签 / 隐藏所有便签

常见问题

屏幕镜像时，可以把计时器窗口添加为来源吗？
可以。点按计时器行上的 窗口 按钮，将其作为真正的窗口打开，它就会出现在镜像或屏幕共享的“添加窗口”列表中。

我隐藏了一个计时器小组件，现在找不到了。
将指针悬停在面板中该计时器所在的行上，即可看到它的位置（以虚线框标出）；或者按下 对齐，让它回到面板旁边。

Remote Controller（iPhone）

使用 Remote Controller 应用，你可以在 iPhone 上操控计时器：开始和暂停、 加减 30 秒、调整小组件大小、把它拖到 Mac 屏幕上的其他位置、将其隐藏，或启动预设计时器。 使用时需要在同一 Wi-Fi 下的 Mac 上运行 StickyPresenter。

首次连接　打开应用后，它会列出在附近找到的 Mac。选择你的 Mac，然后点按 Mac 菜单栏中的计时器图标， 输入 遥控器 下显示的四位数 配对码。配对码一致后，Mac 会记住这台 iPhone， 此后只要打开应用，就会自动连接。如需切换到另一台 Mac，请点按遥控器右上角的连接状态指示，然后选择 断开连接并重新选择。

找不到我的 Mac。请依次检查以下几点：

  • Mac 上的 StickyPresenter 正在运行：确认菜单栏中有它的图标。关闭所有窗口并不会退出应用，但退出应用后，遥控器就无法找到它了。
  • 两台设备连接的是同一个 Wi-Fi。访客网络，或其中一台设备使用蜂窝网络时，都无法连接。
  • iPhone 上已允许访问本地网络：设置 → 隐私与安全性 → 本地网络 → Remote Controller。
  • Mac 上已允许访问本地网络：系统设置 → 隐私与安全性 → 本地网络 → StickyPresenter。
  • 关闭所有 VPN。VPN 常常会让同一网络中的其他设备无法被发现。

提示配对码不一致。请确认你输入的是 Mac 上菜单栏 → 遥控器 下当前显示的配对码。 如果你按过 生成新配对码，配对码就已经变了。此外，当 Mac 处于睡眠状态或未连接 Wi-Fi、始终没有响应时， 也会出现同样的提示。

别人能控制我的计时器吗？除非你把配对码告诉对方，否则不能。Mac 只接受输入了正确配对码的遥控器， 以及此前已通过配对码验证的遥控器。如果你曾把配对码给别人看过，想要撤销，可以通过菜单栏 → 遥控器 → 生成新配对码 重新生成配对码，或通过 忘记已配对的遥控器 清除所有已记住的遥控器。详情请参阅 Remote Controller 隐私政策。
