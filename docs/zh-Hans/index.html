讲稿和时间，始终在眼前

StickyPresenter 是一款轻巧的 macOS 菜单栏应用。它让便签、倒计时和提词器悬浮在全屏 Keynote 或任何演示文稿之上，演讲时备注和时间一目了然。

  • 悬浮便签：始终显示在全屏幻灯片上方，提供六种颜色，可调整透明度和字号，还能锁定，避免误改。
  • 计时器：可自由调整大小的倒计时小组件，时间到时会响起提示音，边框也会闪动提醒。还可以在单独的窗口中打开，通过屏幕共享或 AirPlay 分享出去。
  • 提词器：讲稿自动滚动，速度和字号均可调节，并支持镜像模式。
  • 常驻菜单栏：没有程序坞图标，也不会多出需要照看的窗口。

配套应用

iPhone 版 Remote Controller

演讲时，Mac 往往不在手边。Remote Controller 把计时器交到你手中：开始和暂停、加 30 秒、 调整小组件大小；如果它挡住了幻灯片，还能把它拖到 Mac 屏幕上的其他位置。它通过局域网连接， 无需注册账户，也无需任何设置。
