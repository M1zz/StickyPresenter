เริ่มต้นใช้งาน

StickyPresenter อยู่บนแถบเมนูของคุณ (ไอคอน 📝) คลิกที่ไอคอนเพื่อสร้าง โน้ตแปะ เปิดตัวจับเวลา หรือเริ่มเครื่องบอกบท แอปนี้ไม่มีไอคอนบน Dock และทำงานเงียบ ๆ อยู่เบื้องหลัง

ฟีเจอร์

  • โน้ตแปะแบบลอย — อยู่เหนือ Keynote แบบเต็มจอได้เสมอ มี 6 สี ปรับความโปร่งใส ขนาดตัวอักษร และล็อกได้
  • ตัวจับเวลา — วิดเจ็ตนับถอยหลังทรงสี่เหลี่ยมจัตุรัสที่ปรับขนาดได้ เปลี่ยนธีม (สว่าง / มืด) แสดง / ซ่อน จัดเรียงไว้ข้างแผงควบคุม หรือเปิดแยกเป็นหน้าต่างของตัวเองเพื่อใช้กับการแชร์หน้าจอและ AirPlay ได้ มีเสียงเตือนและขอบกะพริบเมื่อหมดเวลา
  • เครื่องบอกบท — บทพูดที่เลื่อนขึ้นเองอัตโนมัติ ปรับความเร็วและขนาดตัวอักษรได้ พร้อมโหมดกลับด้านกระจก

คำสั่งบนแถบเมนู

การทำงานตำแหน่ง
โน้ตใหม่แถบเมนู → โน้ตใหม่
สร้างจากคลิปบอร์ดแถบเมนู → สร้างจากคลิปบอร์ด
เปิดตัวจับเวลาแถบเมนู → ตัวจับเวลา
เครื่องบอกบทแถบเมนู → โหมดเทเลพรอมป์เตอร์
แสดง / ซ่อนโน้ตทั้งหมดแถบเมนู → แสดงโน้ตทั้งหมด / ซ่อนโน้ตทั้งหมด

คำถามที่พบบ่อย

เพิ่มหน้าต่างตัวจับเวลาเป็นแหล่งภาพตอนสะท้อนหน้าจอได้ไหม
ได้ ใช้ปุ่ม หน้าต่าง ในแถวของตัวจับเวลาเพื่อเปิดเป็นหน้าต่างจริง ซึ่งจะปรากฏในรายการ "เพิ่มหน้าต่าง" ของการสะท้อนหน้าจอหรือการแชร์หน้าจอ

ซ่อนวิดเจ็ตตัวจับเวลาไว้แล้วหาไม่เจอ
วางเมาส์เหนือแถวของตัวจับเวลานั้นในแผงควบคุมเพื่อดูตำแหน่ง (จะมีกรอบเส้นประแสดงขึ้น) หรือกด จัดแนว เพื่อนำกลับมาไว้ข้างแผงควบคุม

Remote Controller (iPhone)

แอป Remote Controller ช่วยให้คุณควบคุมตัวจับเวลาจาก iPhone ได้ ทั้งเริ่มและหยุดชั่วคราว เพิ่มหรือลดเวลา 30 วินาที ปรับขนาดวิดเจ็ต ลากไปวางที่อื่นบนหน้าจอ Mac ซ่อนวิดเจ็ต หรือเริ่มตัวจับเวลาที่ตั้งไว้ล่วงหน้า โดยต้องเปิด StickyPresenter ไว้บน Mac ที่เชื่อมต่อ Wi-Fi เดียวกัน

การเชื่อมต่อครั้งแรก เปิดแอปแล้วแอปจะแสดงรายการ Mac ที่พบอยู่ใกล้ ๆ เลือกเครื่องของคุณ จากนั้นคลิกไอคอนตัวจับเวลาบนแถบเมนูของ Mac แล้วป้อน รหัสจับคู่ 4 หลักที่แสดงอยู่ใต้ รีโมต เมื่อรหัสตรงกัน Mac จะจดจำ iPhone เครื่องนั้นไว้ ครั้งต่อไปแอปจะเชื่อมต่อเองทันทีที่เปิด หากต้องการ เปลี่ยนไปใช้ Mac เครื่องอื่น ให้แตะไฟแสดงสถานะการเชื่อมต่อที่มุมขวาบนของรีโมต แล้ว เลือก ยกเลิกการเชื่อมต่อแล้วเลือกใหม่

หา Mac ไม่เจอ ให้ตรวจสอบตามลำดับดังนี้

  • StickyPresenter เปิดอยู่บน Mac หรือไม่ ดูได้จากไอคอนบนแถบเมนู การปิด หน้าต่างทั้งหมดไม่ได้ทำให้แอปปิด แต่ถ้าออกจากแอป รีโมตจะหา Mac ไม่เจอ
  • อุปกรณ์ทั้งสองเชื่อมต่อ Wi-Fi เดียวกัน หรือไม่ เครือข่ายสำหรับแขก หรือการที่ อุปกรณ์เครื่องใดเครื่องหนึ่งใช้เน็ตมือถือ จะใช้งานไม่ได้
  • อนุญาตเครือข่ายภายในบน iPhone แล้วหรือยัง ที่ การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → เครือข่ายภายใน → Remote Controller
  • อนุญาตเครือข่ายภายในบน Mac แล้วหรือยัง ที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เครือข่ายภายใน → StickyPresenter
  • ปิด VPN ทุกตัว เพราะ VPN มักทำให้มองไม่เห็นอุปกรณ์อื่นในเครือข่ายเดียวกัน

ขึ้นข้อความว่ารหัสจับคู่ไม่ตรงกัน ตรวจสอบว่าคุณป้อนรหัส ที่แสดงอยู่ในขณะนี้ใต้แถบเมนู → รีโมต บน Mac หากคุณเคยกด สร้างรหัสจับคู่ใหม่ รหัสจะเปลี่ยนไปแล้ว

เมื่อเชื่อมต่อไม่สำเร็จ ตอนนี้แอปจะบอกสาเหตุและสิ่งที่ต้องทำแยกกันให้ ดูสรุปได้ที่ เมื่อเชื่อมต่อไม่ได้

คนอื่นจะควบคุมตัวจับเวลาของฉันได้ไหม ไม่ได้ เว้นแต่คุณจะให้รหัสกับเขา Mac จะยอมรับเฉพาะรีโมตที่ป้อนรหัสถูกต้อง และรีโมตที่เคยผ่านรหัสมาก่อนแล้วเท่านั้น หากคุณเผลอให้ใครเห็นรหัสและต้องการยกเลิก ให้ไปที่แถบเมนู → รีโมต → สร้างรหัสจับคู่ใหม่ เพื่อสุ่มรหัสใหม่ หรือ ลืมรีโมตที่จับคู่ไว้ เพื่อล้างรีโมตที่จดจำไว้ทั้งหมด ดูรายละเอียดได้ที่ นโยบายความเป็นส่วนตัวของ Remote Controller
