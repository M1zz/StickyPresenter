Primeiros passos

O StickyPresenter fica na barra de menus (o ícone 📝). Clique nele para criar notas adesivas, abrir os timers ou iniciar o teleprompter. O app não tem ícone no Dock e funciona discretamente em segundo plano.

Recursos

  • Notas adesivas flutuantes: ficam por cima do Keynote em tela cheia, com 6 cores, opacidade e tamanho de fonte ajustáveis, e cadeado.
  • Timers: widgets quadrados de contagem regressiva que você pode redimensionar, trocar de tema (claro / escuro), mostrar / ocultar, alinhar ao lado do painel ou abrir em uma janela própria para compartilhamento de tela e AirPlay. Um sinal sonoro e uma borda pulsante avisam quando o tempo acaba.
  • Teleprompter: roteiro com rolagem automática, velocidade e tamanho de fonte ajustáveis, e modo espelhado.

Perguntas frequentes

Posso adicionar a janela do timer como fonte ao espelhar a tela?
Sim. Use o botão Janela na linha de um timer para abri-lo como uma janela de verdade, que aparece na lista de "adicionar janela" do espelhamento / compartilhamento de tela.

Ocultei um widget de timer e não consigo encontrá-lo.
Passe o cursor sobre a linha do timer no painel para ver onde ele está (um contorno tracejado) ou clique em Alinhar para trazê-lo de volta para o lado do painel.

Remote Controller (iPhone)

O app Remote Controller controla seus timers pelo iPhone: inicie e pause, adicione ou tire 30 segundos, redimensione o widget, arraste-o para outro lugar da tela do Mac, oculte-o ou inicie um timer predefinido. É preciso que o StickyPresenter esteja aberto em um Mac na mesma rede Wi-Fi.

Primeira conexão. Abra o app e ele mostra os Macs que encontrar por perto. Escolha o seu, clique no ícone do timer na barra de menus do Mac e digite o Código de pareamento de quatro dígitos exibido em Controle remoto. Quando o código confere, o Mac memoriza aquele iPhone e, a partir daí, o app se conecta sozinho sempre que você o abrir. Para trocar de Mac, toque no indicador de conexão no canto superior direito do controle e escolha a opção para desconectar e escolher outro Mac.

O app não encontra meu Mac. Verifique, nesta ordem:

  • O StickyPresenter está aberto no Mac: procure o ícone na barra de menus. Fechar todas as janelas não encerra o app, mas, se você encerrá-lo, o controle deixa de encontrá-lo.
  • Os dois dispositivos estão na mesma rede Wi-Fi. Uma rede de convidados, ou um dos dispositivos usando dados móveis, não funciona.
  • A Rede Local está permitida no iPhone: Ajustes → Privacidade e Segurança → Rede Local → Remote Controller.
  • A Rede Local está permitida no Mac: Ajustes do Sistema → Privacidade e Segurança → Rede Local → StickyPresenter.
  • Desative qualquer VPN. Ela costuma ocultar os outros dispositivos da mesma rede.

Aparece a mensagem de que o código de pareamento não confere. Confira se você digitou o código exibido no momento em barra de menus → Controle remoto no Mac. Se você clicou em Novo código de pareamento, o código mudou.

Se a conexão falhar, o app agora diz o motivo e o que fazer — veja o resumo em Quando não conecta.

Outra pessoa pode controlar meus timers? Não, a menos que você passe o código para ela. O Mac só aceita controles que digitam o código certo e controles que já informaram o código antes. Se você mostrou o código para alguém e quer desfazer isso, use barra de menus → Controle remoto → Novo código de pareamento para gerar um código novo, ou Esquecer controles remotos pareados para apagar todos os controles memorizados. Para mais detalhes, consulte a política de privacidade do Remote Controller.
